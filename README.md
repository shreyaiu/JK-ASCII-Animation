# 💜 JK ASCII Animation

✨ A neon-style ASCII video animation project made with love for BTS ARMY!

## 🌟 Features
- Converts videos into ASCII characters.
- Cyan-white terminal glow effects.
- Generates animated MP4 videos.
- Preserves original audio when FFmpeg is available.

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy
- Pillow
- FFmpeg

## 🚀 Installation

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Place your video in the project folder and name it `input.mp4`.

```bash
python main.py
```
